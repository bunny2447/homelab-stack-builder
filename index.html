New to this? Start here
  1. Get a server. Any always-on Linux machine works: an old laptop, a mini PC or a Raspberry Pi 4/5. Ubuntu Server or Debian are easy choices.
  2. Install Docker on it: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # then log out and back in
  3. Note two things you'll need later: your user and group IDs (run id, usually 1000) and the server's IP address (run hostname -I).
  4. Pick apps below, build your stack, download both files into one folder on the server, and run docker compose up -d in that folder.
  5. Open your apps using the links shown under "Open your apps" in the builder.

Don't open these apps to the internet with port forwarding. To reach them away from home, use Tailscale or WireGuard (both in the catalog).
